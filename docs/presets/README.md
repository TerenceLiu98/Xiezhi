# Config Presets

XieZhi ships two documented configuration presets for the current alpha:

- [local-fast.yaml](/Users/terenceliu/Downloads/development/xiezhi/docs/presets/local-fast.yaml:1)
- [ci-guarded.yaml](/Users/terenceliu/Downloads/development/xiezhi/docs/presets/ci-guarded.yaml:1)

You can apply them during setup with:

```bash
xz init --preset local-fast
```

or:

```bash
xz init --preset ci-guarded
```
