# External Alpha Feedback Loop

Use this document to turn alpha feedback into backlog-ready product input.

## Intake Fields

- User / team:
- Repository type:
- Runtime used:
- Preset used:
- Date:

## Capture

- What the user was trying to do
- Where they got stuck
- Whether `xz doctor` helped
- Whether `verify` and `review` felt trustworthy
- What they expected to happen instead

## Buckets

- onboarding
- runtime integration
- planning quality
- verification quality
- review artifact / sharing
- CLI UX

## Replay Into Backlog

For each meaningful report:

1. write a one-line problem statement
2. attach the exact command sequence
3. classify severity: blocker / friction / nice-to-have
4. map it to an existing task or create a new one
